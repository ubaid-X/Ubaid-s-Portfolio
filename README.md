
# Ubaidullah - Personal Portfolio 

Welcome to the repository for my personal portfolio website! 

I built this project to showcase my journey as a Frontend Developer and Computer Science undergraduate. It serves as a central hub for my projects, technical skills, and a way for potential clients or employers to get in touch with me. 

Rather than using a pre-built template, I designed and coded this entirely from scratch to demonstrate my proficiency in modern web technologies, component-based architecture, and UI/UX principles.

## ✨ Key Features

*   **Fully Responsive Design**: Carefully crafted to look stunning and function flawlessly on desktops, tablets, and mobile devices.
*   **Modern Animations**: Utilizes the `motion` library (formerly Framer Motion) for smooth scroll-triggered animations, sliding underlines, and fluid micro-interactions.
*   **Interactive Skills Section**: Custom-built circular SVG progress bars that animate on scroll, paired with animated number counters and informative tooltips.
*   **Dynamic Portfolio Filtering**: An interactive project gallery that filters instantly by category (Web App, UI/UX, API) without reloading the page.
*   **Mobile-First Carousel**: Uses `Embla Carousel` to provide a buttery-smooth, touch-friendly project slider on smaller screens with autoplay capabilities.
*   **Fully Functional Contact Form**: Integrated with **Web3Forms** for reliable email delivery, backed by **React Hook Form** and **Zod** for rigorous, instant client-side validation.
*   **Active Navigation Tracking**: Uses the `IntersectionObserver` API to automatically highlight the current section in the navigation bar as the user scrolls.

## ⚙️ Getting Started Locally

If you'd like to run this project on your own machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ubaid-X/your-portfolio-repo-name.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd your-portfolio-repo-name
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Set up Environment Variables:**
   This project uses Web3Forms for the contact section. You'll need to create a `.env` file in the root directory and add your access key:
   ```env
   VITE_WEB3FORMS_KEY=your-web3forms-access-key-here
   ```

5. **Start the development server:**
   ```bash
   npm run dev
   ```
   The site will be running at `http://localhost:5173`.

### Building for Production
To create an optimized production build:
```bash
npm run build
```
You can preview the production build locally using:
```bash
npm run preview
```
